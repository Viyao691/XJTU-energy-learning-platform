# 手机网页紧凑修订与反馈

范围依据本轮用户16项具体反馈；除首页意见反馈、帮助内容更新覆盖两端外，其余仅手机。桌面首页既有布局、菜单等宽与无装饰线保持。

1. 首页固定视口、四项左侧快捷入口、菜单依附触发项、顶部控件压缩；以360×640/800、390×844实际检查无裁切/滚动。
2. 手机侧栏208px、点外/左滑/ESC收起；非首页静态固定背景、顶栏分界、同背景页脚。压缩标题、卡片、学习与维护页面，保留16px输入与44px触控。
3. 首页两端反馈弹窗，后端持久保存与同源/IP限流，复用管理员SMTP；真实区分通知成功/延迟。隔离测试不发真实邮件。
4. 帮助区分网站与本机功能、密码/验证码/游客、当前预算与隔离、反馈和嵌入配置。用户已选择远程语义嵌入，不采用关键词替代；服务商与密钥尚待确定，禁止隐式付费探测。
5. 各域定向验证后统一生产构建、手机实际观察；发布时备份SQLite与环境再迁移0034，保留原账号和资料。同步已有云端源码交接分支与私有资料页。
