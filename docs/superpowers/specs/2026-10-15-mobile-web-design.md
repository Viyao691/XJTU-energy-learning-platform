# 手机端逐页适配审查

用户要求逐个观察手机界面，字号与图片不宜过大，图片不能只显示一半，交互框和插画必须适配；“手机端视频”已异步询问是否同时制作演示视频，先实施确定的适配审查。

按390×844主视口检查真实网站各业务页及导航/弹窗，360px复核易溢出界面。优先解决已观察到的论文库大标题/四个3D图标、上传页巨大操作区与背景、首页标题图和各页过高装饰区域。用Web专用、仅小屏CSS修正共用问题，再按实际证据补充各页特例。桌面首页/论文顶部冻结区保留，手机修正属于此次用户明确打开的范围。

公开与账号状态使用真实站点；线上论文库为空，内容状态及详情使用独立本地合成样例，不调用模型、不写入生产用户数据。交付逐页审查表，明确空状态、示例状态和未能检查的状态。最终统一构建和部署，只更新前端。

验收：逐页实际画面、字号/图像比例、关键操作与弹窗、横向溢出检查；遇到问题按原因修复后复核。审查不能用几个代表页冒充全站完成。
