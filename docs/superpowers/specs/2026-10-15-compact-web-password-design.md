# Web 紧凑布局与密码登录

用户明确要求六项修改：缩窄左侧展开区；账户信息紧凑完整；登录卡片手机首屏可见并改密码登录、注册设密码、忘记密码切验证码登录；首页删搜索框并压缩菜单；统一此前AI大赛logo；其他页导航展开按钮加宽。首页只重开这些具体区域，其余冻结视觉保留。

使用现有Next/FastAPI/SQLite架构。默认登录提交邮箱和密码；注册保留邮箱验证，另设8–128字符密码。忘记密码只切换验证码登录，不增加未要求的重置流程；旧账号密码为空仍能验证码登录，旧会话保留。后端盐值慢哈希和持久化失败限流，Alembic新增字段/记录，生成OpenAPI类型同步。密码不能返回或记录明文。

布局以360×800和390×844手机视口为检查基线。默认登录无需滚动；注册输入集中、提示简短，去除手机大幅宣传图与冗余留白，保持44px触控目标，16px输入防iOS自动放大。导航宽按内容约224–240px，账户邮箱可换行，短屏可滚动且账户能到达；菜单展开不占整行大面积。logo用用户原始资产，尚待源文件定位，不自行重画。
